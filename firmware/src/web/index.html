    Sky view

    Signal strength

    In dB-Hz. Above about 40 is strong. Signals are weaker near the horizon, but satellites missing from one side of the sky view mean something is blocking the antenna there. Faded bars are satellites the module is not using.

    Bands

    Waiting for the GPS module
    First bandSecond band

    A rover gets an RTK fix quickly and reliably only when the corrections carry two bands from each satellite: L1 and L2 for GPS and GLONASS, E1 and E5b for Galileo, B1I and B2I for BeiDou. The corrections carry only what this base hears. If the second band is on but little is heard on it, the antenna is probably made for L1 only, or its cable loses the higher band.

    Change

    Quick to set up, but the result changes every time, and anything saved in rover coordinates, such as mowing boundaries, moves with it.

    A fixed position keeps rover positions the same from day to day. The antenna must not move afterwards.

    What is height above the ellipsoid?

    GPS measures height from the ellipsoid: a smooth, slightly flattened shape the size of the Earth. Sea level is lumpier, and differs from it by tens of meters depending on where you are. The module needs the height above the ellipsoid.

    The height a survey finds, shown on the Overview as Height (ellipsoid), is already that kind: use it as it is, or press Use the current height while the base is surveyed. A height from a map, a sign or a phone is above sea level: put it in the second box, and it is turned into the first.

    A height a few meters out matters far less than the position: it moves the rovers' heights, not where they are on the ground.

    The current position is where the module says it is now. It is only worth keeping after a long survey, or the base keeps that error for good.
